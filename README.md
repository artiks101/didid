# 🛡️ Discord Admin Logger Bot

Бот для Discord на Python (`discord.py`), который в реальном времени отслеживает действия всех участников с правами **Администратора (Administrator)** и отправляет подробные цветные логи (Embeds) в выделенный канал.

---

## 📋 Возможности бота

### 1. События Журнала Аудита (Audit Logs) от администраторов:
* ⛔ **Блокировки и исключения**: бан, разбан, кик участников (с указанием причины).
* ⏳ **Таймауты (мьюты)**: наложение и досрочное снятие таймаутов, а также автомодерация.
* 🛡️ **Роли**:
  * Создание и удаление ролей;
  * Изменение настроек ролей (название, цвет, позиция);
  * 🚨 **Специальный алерт тревоги**: если какой-либо роли были выданы или сняты права `Administrator`!
  * Назначение и снятие ролей с участников.
* 📁 **Каналы**:
  * Создание и удаление каналов;
  * Изменение названий, тем, медленного режима (slowmode), NSFW статуса;
  * Настройка индивидуальных прав доступа (Overwrites) для ролей и участников.
* 🧹 **Модерация сообщений**:
  * Удаление чужих сообщений администратором;
  * Массовая очистка сообщений (Bulk delete).
* 🏰 **Настройки сервера (Guild Update)**:
  * Смена имени сервера, уровня верификации, AFK-канала, передача прав владельца.
* 🪝 **Вебхуки и инвайты**:
  * Создание, удаление и обновление вебхуков;
  * Создание и удаление приглашений (инвайтов).

### 2. Прямые действия администраторов на сервере:
* ✏️ **Редактирование сообщений**: логирование старого и нового текста со ссылкой на сообщение.
* 🗑️ **Удаление собственных сообщений**: сохранение текста и ссылок на прикрепленные файлы.
* 🔊 **Голосовые каналы**: подключение, отключение и перемещение между комнатами.
* 🚨 **Критический алерт безопасности**: если любому участнику сервера выдаются или снимаются права Администратора в реальном времени!

## 🚀 Быстрый старт и настройка

### 1. Настройка в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и откройте ваше приложение (или создайте новое).
2. В боковом меню выберите раздел **Bot**:
   * Нажмите **Reset Token** и скопируйте токен бота.
   * Прокрутите страницу вниз до блока **Privileged Gateway Intents** и **обязательно включите**:
     * ✅ **Presence Intent** (опционально)
     * ✅ **Server Members Intent** (Обязательно!)
     * ✅ **Message Content Intent** (Обязательно!)
   * Сохраните изменения (*Save Changes*).

### 2. Приглашение бота на сервер
1. В боковом меню перейдите в **OAuth2 ➔ URL Generator**.
2. В блоке **Scopes** отметьте:
   * `bot`
3. В блоке **Bot Permissions** отметьте:
   * **View Audit Log** *(Обязательно для чтения журнала аудита)*
   * **View Channels**
   * **Send Messages**
   * **Embed Links**
   * **Read Message History**
4. Скопируйте ссылку внизу и добавьте бота на ваш сервер.

### 3. Настройка файла `.env`
Откройте файл `.env` в корневой папке и укажите ваши данные:

```env
# Токен вашего бота
DISCORD_BOT_TOKEN=ваш_токен_бота

# ID текстового канала для логов
LOG_CHANNEL_ID=123456789012345678

# (Опционально) ID сервера. Оставьте пустым, если не нужно ограничивать
GUILD_ID=

# Логировать ли ботов-администраторов (True или False)
LOG_BOTS=False
```

> **Как скопировать ID канала в Discord?**
> В Discord откройте: *Настройки пользователя ➔ Расширенные ➔ Режим разработчика (включить)*.
> После этого нажмите правой кнопкой мыши по каналу для логов ➔ **Копировать ID канала**.

## ▶️ Запуск бота

### Способ 1 (через батник):
Просто дважды кликните по файлу **`run.bat`**.

### Способ 2 (через терминал PowerShell / CMD):
```bash
python -m bot.main
```
